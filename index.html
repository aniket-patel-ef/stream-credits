Where do I get a Client ID? (2 minutes, one time)
  1. Open dev.twitch.tv/console/apps and click Register Your Application (Twitch asks for 2FA on your account).
  2. Name: anything unique, like yourname-stream-credits.
  3. OAuth Redirect URLs: paste this exactly:
  4. Category: Broadcaster Suite · Client Type: Public.
  5. Click Create, then Manage, and copy the Client ID into the box above. Client IDs aren't secret.

Connect Twitch first — until then this link only shows demo data.

This link contains your Twitch login token. Don't show it on stream or share it.

  1. Make an Ending scene (or use your existing one).
  2. Add a Browser source, paste the link, set Width 1920 and Height 1080.
  3. Leave “Shutdown source when not visible” unchecked — the source has to stay running during the whole stream to count chat. Leave “Refresh browser when scene becomes active” unchecked too.
  4. Go live as usual. When you switch to the Ending scene, the credits start rolling.
Tips & troubleshooting
  • Check it's counting: right-click the source → Interact, press D for a live stats panel. R rolls the credits, S stops, Shift+X twice wipes the session.
  • New stream = fresh credits. A new session starts automatically when Twitch reports a new broadcast. After you end the stream the last credits stay available (great for an offline screen).
  • Offline / BRB screen: add a second copy with Start rolling: as soon as it loads, Loop and a Solid background. Copies share data; only one of them talks to Twitch.
  • Meld Studio: add it as a browser layer and use As soon as the source loads.
  • Token expiry: Twitch logins expire eventually. If a red notice appears in the corner of the credits, reconnect here and paste the new link into OBS.
